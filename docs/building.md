# Building

NewShell16 is built with [Open Watcom](https://github.com/open-watcom/open-watcom-v2)
(1.9 or 2.0), which cross-compiles 16-bit Windows executables from Linux,
Windows or DOS.

## Installing Open Watcom 2.0 on Linux

```sh
sudo mkdir -p /opt/watcom
curl -L https://github.com/open-watcom/open-watcom-v2/releases/download/Current-build/ow-snapshot.tar.xz \
    | sudo tar xJ -C /opt/watcom

export WATCOM=/opt/watcom
export PATH=$WATCOM/binl64:$PATH        # binl for 32-bit hosts
```

## Building

```sh
wmake           # produces build/newshell.exe
wmake clean
```

The makefile compiles with `-w4 -we`, so warnings fail the build.

Compiler settings: large memory model (`-ml`), Windows prologs with smart
callbacks (`-zWs`), 286 code (`-2`). The executable is marked as a
Windows 3.1 application (`wrc -31`).

## Release and installer

The installer is built with [Win16Setup](https://github.com/ceisserer/Win16Setup)
and bundles the [Retheme16](https://github.com/ceisserer/win31_theme_engine)
theme engine. Both are git submodules in `external/`:

```sh
git submodule update --init
wmake release        # or: python3 tools/release/mkrelease.py
```

Besides Open Watcom this needs gcc (Retheme16's host previewer renders the
theme preview images), GNU make, Python 3 with Pillow and mtools (floppy
image). The result is in `build/release/`:

```
newshell-X.Y.Z/            installation files with SETUP.EXE
newshell-X.Y.Z.zip         the same as a ZIP
newshell-X.Y.Z-disk.img    1.44 MB floppy image
SHA256SUMS
```

The version comes from `VERSION`. The ZIP and the image are reproducible:
file dates are taken from the last git commit (`SOURCE_DATE_EPOCH`).

`dist/SETUP.INF` describes the installation. Two options appear as check
boxes in Setup:

- *Use NewShell as the Windows shell* sets `shell=` and `taskman.exe=` in
  `SYSTEM.INI`; turning it off or removing NewShell restores the old values.
- *Windows 95 look (Retheme16)* installs Retheme16 to `RETHEME\`, adds it to
  `load=` and selects the theme chosen in Setup (with previews).

Setup can be run again from the NewShell group to change these options or
the theme, or to remove NewShell. While NewShell is the running shell, an
update or removal restarts Windows with Program Manager to finish (see
Win16Setup's README, "Shell handover").

## Icons

The icons and the small-image strip in `res/` are generated by
`tools/mkicons.py` (needs Python 3 with Pillow). They are committed, so
this is only needed after changing the artwork:

```sh
python3 tools/mkicons.py
```
